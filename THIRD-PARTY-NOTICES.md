# Third-party notices

## Test fixtures

`tests/fixtures/` contains no third-party page content.

Each parser needs a document to run against, so `tests/fixtures/*.html` are **synthetic**:
minimal markup written for this repository that reproduces only the structure a parser keys
on — the table, the cell order, the attribute names — with our own values. There is no
provider markup, styling, branding or copy in them. Every file says so in a comment on its
first line, and they are generated reproducibly, so a fixture can be regenerated rather
than re-captured when a parser changes.

A few selectors are necessarily the real ones, because they are the interface the parser
matches against: a CSS-module class name, a Tailwind utility class, a framework's
hydration-stream shape. Those are functional identifiers, not expression.

`tests/fixtures/*.json` are small payloads in the response shape each provider's public
pricing API documents — a handful of model identifiers and numbers, trimmed to a few
entries. Prices are facts and a wire format is functional, so there is no third-party
expression in them to license. The largest is under 1.4 KB.

## Prices in `data/prices.json`

Generated by `npm run refresh-prices` from each provider's public pricing page or API. Each
row carries its own `source_url` and `observed_at`. Prices are facts, not creative work.
The file is committed so a fresh clone renders without a network call.

The pricing sources themselves are listed in `src/lib/providers.ts` as
`pricing_source_url`, one per provider.

## Fonts

Instrument Sans is fetched at build time by `next/font/google` and is not vendored here. It
is licensed under the SIL Open Font License 1.1 by its authors.

## Referral links

`src/lib/referrals.ts` holds the product's referral destinations. They are already
served in the live site's HTML. If you run your own instance, replace them with your own or
remove them — they affect outbound links only and never enter price collection,
normalisation, ranking or which offer is marked cheapest.
