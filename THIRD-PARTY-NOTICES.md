## Test fixtures captured from provider pages

`tests/fixtures/` contains small excerpts of each provider's public pricing page or pricing
API response. They exist so the parser for each provider can be regression-tested without a
network call, which is the only way a scraper stays honest over time.

They are trimmed to the pricing table or JSON payload the parser reads — enough to exercise
the parser, and no more. Each file is a capture of the corresponding source below; the
retrieval date of every capture is recorded in this repository's git history.

## Prices in `data/prices.json`

Generated by `npm run refresh-prices` from the public sources above. Prices themselves are
facts, not creative work, and each row carries its own `source_url` and `observed_at`. The
file is committed so a fresh clone renders without a network call.

## Referral links

`src/lib/referrals.ts` holds this deployment's referral destinations. They are already
served in the live site's HTML. If you run your own instance, replace them with your own or
remove them — they affect outbound links only and never enter price collection,
normalisation, ranking or which offer is marked cheapest.
